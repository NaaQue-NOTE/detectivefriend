# 탐정친구

[게임 플레이](https://detectivefriend.duckdns.org/)

계정을 만들고 한 사건을 조사하는 추리·설득 게임입니다. 관계자에게 질문하고 현장의 자료를 확보한 뒤, 사건 추론을 자유롭게 작성해 제출합니다. 계정당 사건 하나를 자동 저장합니다.

질문은 200자, 사건 정리는 2,000자입니다. PC와 모바일에서 플레이할 수 있습니다. 서버가 쉬고 있을 때는 점검 안내가 표시됩니다.

운영자 PC의 로컬 AI를 사용합니다. 현재는 한 번에 한 답변을 생성하며, 다른 이용자가 답변을 받는 중에는 잠시 후 재시도해 주세요. 시험 운영으로 답변 속도와 자연어 판단에 한계가 있습니다.

이 저장소에는 공개 화면과 서버 연결 정보만 게시합니다. 계정·저장·사건 정답·미획득 자료는 운영 서버에서 관리합니다.
